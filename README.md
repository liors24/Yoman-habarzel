# יומן הברזל

שתי אפליקציות אימון אישיות שמותקנות למסך הבית:

- **יומן הברזל** (`/`) – אימון יומי לפי התוכנית, טיימרים לסטים ולמנוחה, הישגים בסוף אימון, תזונה ויומן.
- **המאמן** (`/coach/`) – מאמן AI שמנתח כל אימון אוטומטית, משוב תזונה ויומן.

הסנכרון ביניהן עובר דרך קובץ gist פרטי בחשבון הגיטהאב של המשתמש. הנתונים והמפתחות נשמרים במכשיר בלבד.
